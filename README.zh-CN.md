# write-agents-md

[English](README.md) | [中文](README.zh-CN.md)

用于撰写、重构或精简 **AGENTS.md**（以及 CLAUDE.md、GEMINI.md 等智能体指令文件）的 Agent 技能（AgentSkill）。

这是一个**引导式写作工作流，而非自动生成器**：先只读地收集仓库证据，再通过交互式提问了解你的偏好，最终产出一份极简的根文件，并通过渐进式披露把细节拆分到独立文件中。

## 核心理念

AGENTS.md 中的每个 token 都会在每次请求时被加载，无论是否相关——因此文件越小越好：

1. **指令预算** — 前沿 LLM 只能可靠遵循约 150–200 条指令；臃肿的文件浪费 token 并干扰智能体。
2. **根文件只放三样东西** — 一句话项目描述、包管理器（非 npm 时）、非常规的构建/类型检查命令。
3. **渐进式披露** — 其余内容放入独立文件，用链接引用（如 `docs/TYPESCRIPT.md`）。
4. **描述能力，而非路径** — 文件路径容易过时并污染上下文。
5. **绝不自动生成** — 自动生成的文件总是求全胜过克制；保持人在回路中。

## 工作流程

- **阶段 1：收集证据（只读）** — 扫描 README、包清单、目录结构、已有指令文件、CI 配置，提取事实；不读全量代码。
- **阶段 2：交互式访谈** — 每次最多问 3–4 个问题；证据已能回答的绝不重复问。
- **阶段 3：产出** — 按模板生成极简根文件、将领域规则拆分为分节文件并链接、标记应删除的冗余规则、提供跨工具适配方案（symlink / 导入 / 启动参数）。

## 安装

将整个目录复制到你的智能体技能目录，例如：

- **Pi**：`~/.pi/agent/skills/write-agents-md/`
- **Claude Code**：`~/.claude/skills/write-agents-md/`

然后对智能体说"帮我写 AGENTS.md""精简 CLAUDE.md"等即可触发。

## 项目结构

```text
write-agents-md/
├── SKILL.md                        # 技能入口：理念、工作流、输出质量检查清单
├── assets/templates/               # 输出模板
│   ├── root-AGENTS.md              #   极简根文件模板
│   └── section.md                  #   领域规则分节模板
└── references/                     # 按需查阅的参考
    ├── PRINCIPLES.md               #   为什么极简与渐进式披露
    ├── TOOL-CONVENTIONS.md         #   各智能体平台的指令文件加载约定
    └── EXAMPLES.md                 #   好/坏示例与多级布局
```
